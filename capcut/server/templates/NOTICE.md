The files under `capcut/` are a blank CapCut desktop draft skeleton (draft_info.json,
draft_meta_info.json and sidecar files) derived from the template shipped with the
open-source CapCutAPI project (https://github.com/ashreo/CapCutAPI, Apache License 2.0).
Personal paths and ids were removed. The draft JSON shapes written by `draft.mjs` follow the
conventions documented by that project's pyJianYingDraft module.
